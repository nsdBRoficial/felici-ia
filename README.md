# felici-ia
Desenvolvimento do Feliciá, um serviço digital em formato de Chatbot gamificado. A inovação central é a lógica "down-top": o aplicativo converte a renda mensal em ganhos por hora e por dia. O usuário deve registrar proativamente sua ida ao Senac e ao trabalho para "desbloquear" a visualização de seus ganhos diários.
